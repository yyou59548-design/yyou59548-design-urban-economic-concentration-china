# Package content screening

Screened the actual review-candidate files after selection for GitHub-style personal access tokens, OpenAI-style secret keys, AWS access IDs, private-key headers, email addresses and known local absolute-path patterns. **No pattern matches** were found in these candidate files. This is a limited pattern scan, not a general secret-discovery or legal-compliance guarantee.

No third-party original statistical PDFs, original governmental or institutional Excel workbooks, third-party source archives, population-grid GeoTIFF rasters, historical scripts with embedded operator paths, reviewer comments, or manuscript pre-submission correspondence are included. Each included scientific input is a declared subset of the previously held reference CSVs. No candidate file exceeds 2 MiB.

Source authorship, derivative-data rights and release licensing must still be checked before publication. A passed pattern scan is not a licence to redistribute third-party material.


**当前上传范围**：仅限指定私有GitHub仓库的核心复现快照。任何改为Public、创建公开Release或启用第三方同步，均须先重新审核许可和敏感文件。
