# 《中国城市经济集聚：空间结构与城市贡献的变化》科研复现候选仓库

**状态：仅供发布前审核，尚不能宣称完整论文端到端复现。** 本候选包针对11月3日最新英文稿，抽取了10月28日完整科研归档中能够单独运行的核心实证与合成实验验证。已建立GitHub私有审核仓库，但尚未获得软件许可和完整的第三方数据再分发许可结论；私有仓库不等于公开科研归档。

### 本次实际完成的验证

原始 `joint_state_audit.py` 读取295城市的质量及代表点，从WGS84椭球Albers投影重新计算坐标和带宽矩阵，在已归档的150个连续峰位置重新计算各城市贡献，组成120组相邻年度比较和30条规格序列。输入压缩后，输出的四份CSV与完整归档运行结果逐字节相同。4个规格共8次贡献者转换，转换组最低Jaccard为0.9689207388，120条有限变化分解的最大恒等式残差为6.31e-15。

独立编写的 `experiment_b_reproduce.py` 直接利用四城市高斯场及驻点方程，对81个周围GDP分配状态重新求平局门槛和连续峰位置，逐行与历史参考结果比较。81次求解均通过，门槛最大差约为6.9e-15，且每个解具有负定Hessian及A、B为前两大贡献者。

运行：

```bash
python -m pip install -r requirements-core.txt
python tests/run_core_checks.py
```


### 2026年11月4日新增独立数学验收

`tests/run_independent_oracles.py` 不调用历史峰值位置或原生产计算器，而是重新求解四城市实验B的81个平局根、两种相反的事件顺序、无标签拓扑反射构造的数值等价性，以及295城GDP与经纬度输入所确定的2021年珠三角名义GDP及可比增长链的峰值与门槛。另增加四种篡改情形的完整性拒绝测试。上述测试已在本地实际执行，属于**新增的独立检验**，但不是2,062个完整空间场和全部轮廓的从零再计算。

10月28日完整科研归档的三卷ZIP已实际检查：5,403个互不重复路径、全部ZIP CRC及5,401个已解压科研文件SHA256通过，原输入保护清单也通过。完整归档本身不放入这个私有GitHub；`scripts/audit_full_archive.py` 可在本地重复检查。当前执行环境因缺少 `xlrd==2.0.1` 未能运行完整四阶段compact，所以不将其记为本轮通过。具体证据、操作和局限见 `docs/REPRODUCTION_COVERAGE_20261104.md`。

### 不能据此宣称的事项

这套核心程序**使用了已归档的峰和连通分量坐标**，没有重新发现全部连续峰或重建全部高值轮廓；没有完成2,062个空间场的七尺度全量重算，也没有从全部原始统计出版物逐页认证2,950条原始数据。完整科研归档包含上述其他计算程序与历史检验材料，但它们不自动构成当前发布包的新鲜运行证据。

仓库公开前还需要确认衍生数据及坐标的再分发权限、作者信息、代码许可证，并完成全量科研复现的另行核查。审稿意见和回复、第三方原始出版物以及历史缓存均不放入这一公开候选包。具体见 `docs/PUBLICATION_GATE_CN.md`。
